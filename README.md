# Business Finance

Учебное семейное приложение для учёта доходов, расходов и взаиморасчётов четырёх участников.

## Текущее состояние

- **Этап 1:** статический предварительный интерфейс на Next.js с вымышленными данными.
- **Важно:** кнопок сохранения, входа и общей базы пока нет — данные в интерфейсе демонстрационные.
- **Этап 2 (план):** Cloudflare Worker как защищённый API и Cloudflare D1 как общая база.
- **Позже:** интеграция RealtyCalendar и Telegram-уведомления о задачах.

## Локальная разработка

```bash
npm ci
npm run dev
```

Откройте адрес, который покажет Next.js.

## GitHub Pages

Next.js собирается в статический каталог `out/` с `basePath: /business-finance`.
Workflow `.github/workflows/deploy.yml` собирает проект и загружает сборку в Pages при изменении `main`.

После слияния Pull Request владелец репозитория должен **однократно** выбрать
`Settings → Pages → Build and deployment → Source: GitHub Actions`.

Адрес сайта после активации:
https://vakazarinov.github.io/business-finance/

GitHub Pages размещает только публичный интерфейс; никакие секреты и финансовые данные
нельзя класть в клиентский код, исходные файлы или переменные `NEXT_PUBLIC_*`.

## Безопасность

До подключения серверного API форма ввода намеренно не включена.
Старый код `lib/supabase.ts` не используется в текущем статическом интерфейсе;
не следует возвращать прямой доступ к таблице из браузера с открытыми правами.
Пароли и токены позже будут храниться в секретах Cloudflare Worker.

# Business Finance

Семейное веб-приложение для учёта доходов, расходов и взаиморасчётов четырёх участников: Витя, Маша, Петя и Саша.

## Архитектура

- **GitHub Pages** — публичный статический интерфейс Next.js
- **Cloudflare Worker** — API, семейный пароль, авторизация и проверки
- **Cloudflare D1** — общая база финансовых операций
- **GitHub Actions** — сборка и публикация Pages

## Текущее состояние

Рабочий код интерфейса и API добавлен, но **база и Worker не развёрнуты автоматически**.
Пока в GitHub Actions не указана публичная переменная `NEXT_PUBLIC_API_URL`,
сайт показывает сообщение «Ожидается подключение базы» и не позволяет вводить реальные операции.

Инструкция по запуску: [docs/cloudflare-setup.md](docs/cloudflare-setup.md).

## Возможности первой версии

- Общий семейный пароль и сессии на семь дней
- Добавление, просмотр, редактирование и удаление доходов и расходов
- Последние десять операций и история для расчётов
- Предыдущий календарный месяц, произвольный период или вся история
- Общая прибыль и расчёт распределения между участниками
- Настройка процентов прибыли (пока без фиксации долей по периодам)

Не входят пока: учёт реальных переводов между участниками, экспорт CSV, RealtyCalendar, Telegram-напоминания.

## Локальная разработка

```bash
npm ci
npm run dev
```

Тесты и сборка перед PR: `npm run lint && npm run build`.

## Безопасность

Исходный репозиторий публичный. Никогда не сохраняйте в GitHub
`FAMILY_PASSWORD`, `SESSION_SECRET`, токены Telegram или финансовые данные.
Секреты хранятся только в Cloudflare Worker Secrets.

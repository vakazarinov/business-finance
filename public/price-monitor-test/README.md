# Price Monitor Test — Авито

Тестовый интерфейс: https://vakazarinov.github.io/business-finance/price-monitor-test/

## Как устроено

GitHub Pages (интерфейс) → Supabase Edge Function (API заданий) → временные таблицы Supabase → локальный Python-исполнитель на Windows с Microsoft Edge.

При CAPTCHA исполнитель ставит текущий интервал на паузу, показывает статус на сайте и ждёт кнопки «Продолжить» после ручной проверки в Edge. Новое тестирование очищает только тестовые таблицы.

**Важное ограничение:** GitHub Pages не запускает серверные программы, а GitHub-hosted Actions не позволяет пользователю вручную проходить CAPTCHA в интерактивном браузере. Пока для этого нужен включённый Windows-компьютер с локальным исполнителем. Это не полностью облачное решение.

## Запуск на Windows

1. Скачайте репозиторий через GitHub → Code → Download ZIP: https://github.com/vakazarinov/business-finance
2. Распакуйте ZIP, откройте папку business-finance/public/price-monitor-test в Проводнике.
3. В адресной строке Проводника введите powershell и нажмите Enter.
4. Один раз установите Playwright:

       py -3 -m pip install playwright

5. Запустите исполнитель:

       py -3 worker.py

6. В PowerShell введите пароль Business Finance. Он вводится скрыто и не передаётся в GitHub.
7. Откройте тестовую страницу, войдите с тем же паролем и нажмите «Запустить мониторинг».
8. Держите PowerShell открытым. Для следующих запусков достаточно повторить команду py -3 worker.py.

Microsoft Edge должен быть установлен на Windows. Chromium скачивать не требуется.

## CAPTCHA

Если на экране Edge появится CAPTCHA, приложение покажет статус «Ожидание CAPTCHA». Пройдите проверку в открытом Edge на компьютере с исполнителем, затем нажмите «Я прошёл проверку — продолжить» в веб-приложении. Сборщик повторит этот же интервал, не пропуская его.

## Таблицы

Созданы только две новые таблицы:
- public.price_monitor_test_jobs — очередь и статус задания;
- public.price_monitor_test_prices — цены по окнам.

Финансовые операции и другие бизнес-таблицы не изменяются. Временные данные удаляются при каждом новом запуске (если предыдущий запуск завершён). RLS включён; публичные роли не имеют доступа к таблицам. Доступ через Edge Function по существующей подписанной сессии Business Finance.

## Что измеряем

Сборщик использует передачу checkIn, checkOut и guestsDetailed в URL Авито, читает атрибут content или текст элемента data-marker="item-view/item-price". Значение card_price_rub — цена карточки при указанных датах. **Это не подтверждённый итог бронирования и не обязательно средняя цена за сутки.** Программа не умножает её на количество ночей.

Никаких бронирований или оплат. Не пытайтесь обходить проверки или выполнять интенсивный сбор — доступность и условия использования определяет Авито.

После успешного тестирования переносим UI в нативный раздел Business Finance и при необходимости используем постоянную схему наблюдений.
